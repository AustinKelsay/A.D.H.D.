# ADHD App Packaging and Onboarding Phase (Phase 16)

## Status
Planned.

## Objective
Ship ADHD as an installable product with first-run onboarding that no longer assumes operator familiarity with backend commands.

## In Scope
- desktop packaging/signing baseline
- mobile distribution baseline
- first-run onboarding UX
- Codex/runtime readiness checks surfaced in-app
- app-facing setup guidance replacing curl/operator-first onboarding

## Out of Scope
- enterprise distribution and IAM
- multi-tenant SaaS onboarding

## Exit Criteria
- users can install the app and reach a guided onboarding flow
- the app can explain whether Codex/runtime prerequisites are satisfied
- packaged app builds exist for the target desktop/mobile release paths

## Dependencies
- Phase 11 through Phase 15 delivery
